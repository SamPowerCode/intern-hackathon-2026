Stage 1 — The Lobby

At 09:14 this morning, Mittens Fluffington III — a 3-year-old tabby belonging to the Head of Security — walked across the emergency admin terminal and triggered the VAULT-9 lockdown sequence.

The system captured her raw keystroke log and encoded it into three emergency lock codes using the VAULT-9 proprietary algorithm. Decode them to open the lobby door.

Save the script below as lobby_decoder.py and run it:

python3 lobby_decoder.py
#!/usr/bin/env python3
"""VAULT-9 Emergency Lockdown Decoder v2.1"""

MITTENS_KEYLOG = "fjk39dls02pqzxcv8nm1"


def decode_lockdown(keylog):
    codes = []
    for i in range(3):
        acc = 0
        for j, ch in enumerate(keylog):
            acc = (acc * 31 + ord(ch) + i * 17) & 0xFFFF
        codes.append(acc % 9000 + 1000)
    return codes


if __name__ == "__main__":
    codes = decode_lockdown(MITTENS_KEYLOG)
    print(f"CODE ALPHA : {codes[0]}")
    print(f"CODE BETA  : {codes[1]}")
    print(f"CODE GAMMA : {codes[2]}")
Answers are the three integers printed by the script. Answers are case-insensitive. You won't be told which are wrong — only how many.
