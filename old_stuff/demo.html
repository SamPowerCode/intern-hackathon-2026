Stage 1 — The Warmup

Welcome to the hackathon! This first stage is a warmup to get you comfortable with the format. Read carefully — you need all three answers correct to advance.

Consider the following Python function:

def mystery(n):
    if n <= 1:
        return n
    return mystery(n - 1) + mystery(n - 2)

Answer all three questions:

  1. What does mystery(7) return?
  2. What is the name of the algorithmic technique this uses?
  3. What is the Big-O time complexity? Use the form O(x^n).
Answers are case-insensitive and whitespace is ignored. You won't be told which answers are wrong — only how many.
