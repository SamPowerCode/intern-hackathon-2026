The security camera caught Mittens in the act. The paranoid lead engineer always embedded backup override codes into surveillance images — a technique only he documented. His notes were recovered from the recycle bin:

"Override codes hidden in R channel, every 1st pixel (i.e. every pixel), starting at pixel 0. LSB steganography. Standard."

The file mittens_cam.png is in your session 2 ZIP. A partial extraction script is also included as extract_template.py. Fill in STEP, run it, and read off the three override codes. 

pip install Pillow
python3 extract_template.py
The three answers are the three comma-separated integers printed by the script. Make sure mittens_cam.png is in the same directory as the script.
