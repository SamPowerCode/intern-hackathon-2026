The vault management database holds the master override codes. Mittens walked on the delete key — some records are now marked deleted. But SQLite doesn't truly forget.

The SQL editor below is connected to vault_records.db. Use Ctrl+Enter or the Run button to execute queries.

  1. One vault record was quietly erased during the incident. What is its emergency code?
  2. The lockdown triggered a cascade of automatic transaction reversals. What was the total amount reversed? (integer, no decimals)
  3. Something accessed a vault at exactly the moment the lockdown began. Find that vault's emergency code.
Tip: SELECT name FROM sqlite_master WHERE type='table'; lists tables. PRAGMA table_info(tablename); shows columns.
